# Arkvoid Icons

Supply the following PNG files in `public/icons/` before production release:

| File | Dimensions | Purpose | Notes |
| :--- | :--- | :--- | :--- |
| `icon-192.png` | `192 × 192 px` | `any` | Standard PWA home screen icon on Pearl (`#FBFAF7`) background |
| `icon-512.png` | `512 × 512 px` | `any` | High-resolution PWA splash and store icon on Pearl (`#FBFAF7`) background |
| `icon-maskable-512.png` | `512 × 512 px` | `maskable` | Maskable icon keeping the Arkvoid mark inside the inner 80% safe circle (`410 × 410 px`) |
| `apple-touch-icon-180.png` | `180 × 180 px` | `apple-touch-icon` | iOS Home Screen icon, opaque Pearl (`#FBFAF7`) background, no transparency |

`favicon.svg` (`public/icons/favicon.svg`) is already included and wired in `index.html`.
