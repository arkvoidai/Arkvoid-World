# Arkvoid Texture Assets

Place CC0 PBR texture sets from Poly Haven or similar sources in this directory or subdirectories.
Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`.

File names are parsed automatically according to Poly Haven conventions (e.g. `forest_ground_04_diff_1k.jpg`, `stone_nor_gl_2k.png`, `timber_arm_1k.jpg`).
Other extensions (.exr, .zip, .tif) are ignored.
